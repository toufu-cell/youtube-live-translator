## 操作と計測

1. 初回とCache済みのモデル準備時間・取得ファイル・容量を記録します。
2. 開始・停止、元音声、ポップアップを閉じた動作、別タブ・全画面・シアター表示を確認します。
3. 一時停止・再開、シーク、広告、本編復帰、別動画・外部ページへの遷移、動画終了を確認します。
4. GPU利用不可、モデル取得失敗、推論停止時の表示と資源解放を確認します。
5. ライブ配信と録画を区別し、発言単位の表示遅延・提示率・修正・省略・無出力を記録します。

ポップアップの開発者ツールで`await chrome.runtime.sendMessage({type:'GET_METRICS'})`を実行すると、直近120件の区間メタデータを確認できます。イベント全体の中央値・p95・提示率は、対象区間を明確にして別途集計します。
